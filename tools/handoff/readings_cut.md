## Where fixes must go
data/readings33.js is generated by tools/m33/run.sh (readings33b.json, then tools/m33/fixes.json, absent.json,
fixes_m39.json, then the TXT/TXTEN string replacements, then the file is written). To keep a fix after a rebuild, add it in run.sh
after fixes_m39 is applied. The simplest way: a new tools/m33/tails.json with entries
[mass, type, field, old_suffix, new_suffix] (also ref fixes), applied in run.sh just before the file is written. Then apply the same
script once to the current data/readings33.js. Helpers in /tmp/rt (these may be gone): find2.py "<words>" N searches
tools/orat39/m39lin.txt (1939), find33.py "<words>" N p1,p2 searches /home/claude/m33/lines.json (1933 OCR, page = p33).
The 1933 OCR in /home/claude/m33/lines.json is the real source of readings33 and is a good second witness.
Accents: tools/orat39/accdict.json (unaccented to accented) plus checking by hand.
