## Site-wide item
Consonantal i: the orations use "eius" and "Iesum", where the Missal prints "ejus" and "Jesum". The coordinator will convert these by script. This audit folds i/j.

## Why these errors existed
- **Readings:** they came from the 1933 Missal read via tools/m33 and Divinum Officium. That carried over DO/Roman punctuation (',' where the 1939 print has ':'), lost words at page and line breaks ("ter" for "Pater", a missing ending), and kept the Vulgate verse ending where the Missal stops early.
- **Common Masses:** these used the 1959 St Dominic Missal's Common numbers, not the 1939 Missal's own assignments, so the wrong readings and Alleluia verses followed.

## Scripts (tools/audit/scripts/A4/)
- **audit.py:** per-Mass comparison against m39lin.txt.
  - keep() is fixed so that inserted punctuation and case changes in OCR-equal words are no longer hidden.
  - rwin.json maps a Mass to its Common page.
- **view.py:** renders a half page (`python3 view.py PDF L|R`).
- **show.py:** prints the site orations.
- **fixgen.py:** builds an entry from a diff index. Case fixes now write capitals without an accent.
- **addfix.py:** append-only. `python3 addfix.py b_KEY.py` appends that body's entries to fixes/A4.json. It reads the current A4.json, so entries already applied are never regenerated.
  - The b_*.py files are the session 2 decisions, one per Mass or group.
  - dec.py and dec2*.py are the old regenerating builders. They fail once the fixes are applied, so do not run them.
- **rep.py:** appends report lines and moves the "Where I stopped" line.

To resume:
1. `cp tools/audit/scripts/A4/* /tmp/A4/`.
2. `cd /tmp/A4`.
3. `python3 audit.py KEY`.
4. Use view.py for the pages.
5. Write b_KEY.py.
6. `python3 addfix.py b_KEY.py`.
